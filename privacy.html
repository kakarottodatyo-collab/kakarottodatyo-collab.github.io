プライバシーポリシー（ytauto-sim）

最終更新日：2026年11月19日

1. このツールについて

ytauto-sim は、YouTube チャンネル「Marionette」の運営者が自分のチャンネルの運営だけに使う個人用ツールです。運営者以外の方の Google アカウントでは使用しません。

2. 取得する情報と使い道

  • YouTube Data API（youtube スコープ）：運営者のチャンネル情報の確認、動画のアップロード、公開設定・予約の変更、アップロード済み動画の状態確認に使います。
  • YouTube Analytics API（yt-analytics.readonly スコープ）：運営者のチャンネルの再生数、視聴時間、平均視聴率、高評価、コメント数、登録者の増減などの集計値を読み取り、次の動画の企画に使います。視聴者個人を特定する情報は取得しません。

3. 保存と管理

  • Google から受け取る認証情報（リフレッシュトークン）は、運営者のパソコン内の非公開の設定フォルダにだけ保存します。
  • 取得した統計は、運営者のパソコン内に保存し、動画づくりの分析にだけ使います。

4. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の利用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。また、YouTube API サービスを利用しており、YouTube 利用規約および Google プライバシーポリシーが適用されます。

6. アクセスの取り消し

本ツールに与えたアクセスは、Google アカウントの「サードパーティによるアクセス」からいつでも取り消せます。取り消した場合、保存されたトークンは使えなくなります。

7. お問い合わせ

このページを公開しているリポジトリの Issues からお問い合わせください。

English summary: ytauto-sim is a personal tool used only by the owner of the "Marionette" YouTube channel. It uses the YouTube Data API to upload and schedule the owner's own videos, and the YouTube Analytics API (read-only) to read aggregated statistics of the owner's own channel. Tokens and statistics are stored only on the owner's computer and are never sold or shared. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: Issues of the repository hosting this page.
